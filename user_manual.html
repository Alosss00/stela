Bab 1. Pendahuluan

1.1 Tujuan Dokumen

Dokumen User Manual ini bertujuan untuk memandu pengguna dalam menggunakan aplikasi STELA (Smart Toka Electronic Letter Assign). Panduan ini merinci setiap langkah operasional sesuai dengan masing-masing peran (role) sehingga pengguna dapat berinteraksi dengan sistem secara optimal.

1.2 Pengenalan Aplikasi STELA

STELA adalah aplikasi berbasis web yang memfasilitasi penugasan elektronik (Electronic Letter Assign), manajemen data pegawai, pemantauan sertifikasi, serta alur persetujuan (approval) berjenjang hingga ke tingkat Kepala Teknik Tambang (KTT).

1.3 Target Pengguna & Hak Akses

Aplikasi ini memiliki 5 hak akses utama:

  • User (Pegawai): Karyawan yang mengajukan data diri dan memantau status penunjukan.
  • Dept (Atasan Langsung): Kepala Departemen yang memantau staf dan proses resign.
  • Admin (HR): Personalia yang memverifikasi data karyawan dan mencetak laporan operasional.
  • KTT (Kepala Teknik Tambang): Otoritas tertinggi yang memberikan persetujuan akhir pada surat penunjukan.
  • Superadmin (Administrator): Tim IT yang mengelola seluruh konfigurasi, hak akses, dan master data.

1.4 Persyaratan Sistem

Aplikasi ini dapat diakses menggunakan peramban web modern seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge versi terbaru yang terhubung ke jaringan intranet/internet organisasi.

Bab 2. Memulai Aplikasi

2.1 Cara Mengakses dan Login

Untuk masuk ke dalam aplikasi STELA, ikuti langkah berikut:

  1. Buka browser dan akses URL sistem STELA.
  2. Pada halaman login, masukkan Username/Email dan Password Anda.
  3. Klik tombol Masuk / Login. Sistem akan mendeteksi role Anda secara otomatis dan mengarahkan ke Dashboard yang sesuai.
[SCREENSHOT] Halaman Login

2.2 Ganti Password (Change Password)

Demi keamanan, sangat disarankan untuk mengubah kata sandi Anda secara berkala.

  1. Akses menu profil/pengaturan di pojok atas layar.
  2. Pilih Ubah Kata Sandi (Change Password).
  3. Masukkan kata sandi lama, lalu ketikkan kata sandi baru.
  4. Klik tombol Simpan untuk menerapkan perubahan.

2.3 Cara Logout

Pastikan Anda selalu keluar dari aplikasi jika menggunakan komputer publik. Klik menu Profil di pojok atas, lalu pilih Logout / Keluar untuk mengakhiri sesi Anda dengan aman.

Bab 3. Panduan Role: User (Pegawai)

3.1 Dashboard Pegawai

Saat Anda berhasil login, halaman pertama adalah Dashboard. Di sini Anda dapat melihat ringkasan status profil Anda, jumlah sertifikat yang Anda miliki, dan notifikasi terkait penunjukan.

[SCREENSHOT] Dashboard User

3.2 Manajemen Data Pribadi (Tambah, Ubah, & Resubmit)

Setiap pegawai wajib melengkapi data profil mereka agar dapat diproses untuk Surat Penunjukan.

  • Input Data: Klik tombol Tambah Data dan isi formulir yang tersedia.
  • Ubah Data: Selama data belum dikunci/disetujui, Anda dapat memperbarui informasi dengan memilih Edit.
  • Resubmit (Pengajuan Ulang): Jika data Anda ditolak oleh Admin, sistem akan menampilkan alasan penolakan. Anda dapat memperbaiki data dan menekan tombol Resubmit.

3.3 Status Karyawan & Detail

Melalui menu Status Karyawan, Anda dapat melihat apakah dokumen Anda masih dalam tahap Review, sudah di-Verifikasi, atau Ditolak. Informasi detail juga disajikan pada halaman Detail Pegawai.

3.4 Manajemen Sertifikat

Menu Sertifikat menampilkan seluruh sertifikasi yang Anda miliki beserta status keabsahannya. Jika sertifikat ditolak atau kedaluwarsa, Anda dapat melakukan pengajuan ulang melalui menu Resubmit Certificate.

3.5 Surat Penunjukan (Appointments)

Jika Anda telah ditugaskan, Surat Penunjukan elektronik akan muncul di menu Appointments. Anda dapat melihat detail tugas dan mengunduh surat tersebut apabila sudah disetujui secara final.

Bab 4. Panduan Role: Dept (Atasan Langsung)

4.1 Dashboard Departemen

Berbeda dengan User biasa, Dashboard Kepala Departemen akan menampilkan agregasi statistik jumlah pegawai di bawah departemennya, status persetujuan, dan rangkuman data operasional.

4.2 Memantau Daftar Pegawai Bawahan

Melalui menu Employees, Anda dapat melihat seluruh karyawan di departemen Anda. Anda dapat membuka detail setiap pegawai untuk memantau kelengkapan profil dan sertifikat mereka.

[SCREENSHOT] Daftar Karyawan Departemen

4.3 Menangani Proses Pegawai Resign

Jika ada anggota tim yang mengundurkan diri, Dept Head dapat memproses dan menandai status pengunduran diri pegawai tersebut melalui menu spesifik Employees Resign.

4.4 Pemantauan Sertifikat & Penunjukan

Departemen dapat memastikan bahwa bawahan mereka memiliki sertifikat yang masih berlaku dan memantau draf Surat Penunjukan (Appointments) yang melibatkan staf mereka sebelum disahkan.

Bab 5. Panduan Role: Admin (HR)

5.1 Memverifikasi Data Karyawan

Tugas utama Admin adalah menjaga keabsahan data. Melalui menu Verifikasi Pegawai, Admin mengecek kelengkapan dan validitas dokumen yang diajukan oleh User.

Catatan: Jika dokumen tidak sah, Admin berhak menekan tombol Tolak (Reject) dan wajib menyertakan catatan penolakan agar pegawai bisa melakukan Resubmit.

5.2 Manajemen Master Data Dasar

Admin memiliki akses ke tabel master operasional, yaitu:

  • Sertifikasi: Mengelola jenis-jenis sertifikat yang diakui.
  • Kompetensi: Menentukan kompetensi dan sub-kompetensi wajib.
  • Posisi: Daftar jabatan yang ada di perusahaan.
  • Area Pengawasan: Titik-titik operasional yang menjadi tanggung jawab pegawai.

5.3 Mengelola Surat Penunjukan (Appointments)

Admin merancang, menerbitkan, dan mengawasi Surat Penunjukan untuk pegawai tertentu berdasarkan kompetensi yang telah divalidasi. Proses ini diatur pada modul Appointments.

5.4 Laporan & Ekspor Data

Admin dapat mengunduh laporan keahlian (Kompetensi) dalam format yang bisa dicetak/diexcel melalui fitur Laporan & Export.

Bab 6. Panduan Role: KTT (Kepala Teknik Tambang)

6.1 Persetujuan (Approval) Surat Penunjukan

Modul utama KTT adalah halaman Approval. Setelah Admin memproses Surat Penunjukan elektronik, surat tersebut akan masuk ke kotak masuk KTT.

Langkah persetujuan:

  1. Buka halaman Approval.
  2. Tinjau detail pegawai, kompetensi, dan area pengawasan.
  3. Jika setuju, klik tombol Approve. Dokumen secara sistem akan sah dan terdistribusi ke Admin serta Pegawai terkait.

Bab 7. Panduan Role: Superadmin (Administrator)

7.1 Pengelolaan Pengguna (Users, Roles, & Permissions)

Superadmin berwenang menambah akun pengguna secara manual, mengubah kata sandi mereka, serta mengatur peran (Role) dan hak akses (Permissions) untuk setiap akun melalui menu Users.

7.2 Manajemen Master Data Keseluruhan

Selain master data yang dipegang Admin, Superadmin juga mengatur data root perusahaan seperti entitas Perusahaan (Companies) dan daftar Departemen (Departments).

7.3 Pemantauan & Bypass Sistem

Superadmin dapat memantau status persetujuan secara global (termasuk status Approval KTT) serta memiliki hak istimewa untuk mengedit data pegawai meskipun sedang dalam proses (Bypass/Supervision).

[SCREENSHOT] Monitoring Logs & Dashboard Superadmin

7.4 Pengaturan Sistem Lanjut (Settings)

Terdapat fitur kritikal bagi tim IT:

  • Backup & Restore: Mencadangkan data sistem atau memulihkan dari cadangan sebelumnya.
  • Monitoring Logs: Memantau jejak rekam segala perubahan di dalam sistem (Audit Trail).
  • Elasticsearch: Manajemen mesin pencari untuk memastikan pencarian data tetap cepat.
  • Trash (Recycle Bin): Mengembalikan data penting yang tidak sengaja terhapus.

Bab 8. FAQ & Troubleshooting Umum

8.1 Lupa Kata Sandi (Password)

Tanya: Bagaimana jika saya tidak bisa masuk karena lupa password?

Jawab: Segera hubungi Superadmin (Tim IT/Support). Saat ini sistem pengembalian kata sandi dikendalikan penuh oleh Superadmin melalui menu Users Management untuk menjaga keamanan tinggi.

8.2 Data Pengajuan Ditolak

Tanya: Kenapa status profil atau sertifikat saya "Rejected"?

Jawab: Hal ini berarti Admin menemukan ketidaksesuaian (misal foto buram, kedaluwarsa). Silakan cek catatan penolakan pada halaman detail, lalu gunakan tombol Resubmit untuk mengunggah ulang dokumen yang benar.

8.3 Akses Ditolak (Access Denied)

Tanya: Saat membuka tautan tertentu, saya dialihkan kembali ke Dashboard dengan pesan error.

Jawab: Anda mencoba mengakses halaman yang tidak diperuntukkan bagi Hak Akses (Role) Anda. Misalnya, User Pegawai tidak dapat mengakses halaman pengaturan Superadmin. Pastikan Anda hanya menggunakan menu yang ada di sidebar kiri navigasi Anda.
